SCREAMv1

Simulation campaigns using SCREAMv1, the Simple Cloud-Resolving E3SM Atmosphere Model version 1, at global 3.25 km resolution (ne1024pg2).

If you use data from these simulations, please cite the manuscript for the relevant campaign:

  • Four Seasons: 40-day simulations initialized in four different seasons, plus 6-day process impact tests.

    • Donahue et al. 2024 (JAMES)

  • Cess-Potter, 13 months (Aug 2019 - Aug 2020): control and +4K uniform SST warming simulations.

    • Terai et al. 2025 (JAMES)

  • Cess-Potter, 19 months (Aug 2019 - Feb 2021): control and +4K uniform SST warming simulations.

    • Beydoun et al. (in review)

Data access: the simulation data are archived on NERSC HPSS. See Accessing E3SM Data for download instructions.

Run scripts: the scripts originally used to run the Four Seasons simulations are available here. These will not run out-of-the-box; they are provided as guidance for setting up a similar run. Run scripts for the Cess-Potter simulations are not yet archived in this repository.
