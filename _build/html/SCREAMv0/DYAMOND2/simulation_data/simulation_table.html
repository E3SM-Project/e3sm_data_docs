SCREAMv0 DYAMOND2

The DYAMOND2 simulation campaign using SCREAMv0 that was submitted to the DYAMOND2 intercomparison.

If you use data from this simulation campaign, please cite the overview manuscript:

  • Caldwell et al. 2021 (JAMES)

Data access: the simulation data are archived on NERSC HPSS. See Accessing E3SM Data for download instructions.

Run scripts: the scripts originally used to run these simulations are available here. These will not run out-of-the-box; they are provided as guidance for setting up a similar run.
