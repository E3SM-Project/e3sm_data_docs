E3SMv3

The simulation campaign for E3SMv3 was performed with two separate model configurations:

  • v3.LR (lower resolution)

  • v3.RRM (regionally refined model)

If you use data from this simulation campaign, please cite the relevant overview manuscripts.

  • For a general E3SMv3 overview and v3.LR simulations:

    • Xie et al. 2025. The Energy Exascale Earth System Model Version 3: 1. Overview of the Atmospheric Component (JAMES, https://doi.org/10.1029/2025MS005120)

    • Golaz et al. 2026. The Energy Exascale Earth System Model Version 3: 2. Overview of the Coupled System (JAMES, https://doi.org/10.1029/2025MS005302)

  • For v3.RRM simulations:

    • TBD

  • For v3.LR Large Ensemble simulations:

    • TBD

Data access: the simulation data are available on ESGF and NERSC HPSS. See Accessing E3SM Data for download instructions.

Run scripts: the run scripts for E3SMv3 simulations are not yet archived in this repository.
